# Cognitive Reframing Support

用户请求识别灾难化、非黑即白、读心或自责等思维模式时使用。先调用
`theraskill_context`，再用 `theraskill_knowledge_search` 获取检索证据；承认真实约束，不强迫积极化，不做诊断或正式治疗计划。
