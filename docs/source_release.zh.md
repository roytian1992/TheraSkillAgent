# 源码发布与验收记录

版本：0.5.0。初始验收：2026-10-17；最新源码同步验收：2026-10-19。软件开发版本；完整知识、预构建索引与模拟素材尚未公开发布。

## 源码边界

`releases/source-allowlist.json` 是当前源码清单。`scripts/release_source.py` 生成包含文件 hash / 大小的清单，检查链接、大文件和常见凭据形状；`--export` 输出干净源码目录；`--check-git` 检查 Git 跟踪文件没有超出清单。它不会自动执行提交或上传。

Git 管理 Python 代码、12 个内置业务技能、前端源码、配置模板、提示词、schema、文档和少量自编示例。node_modules、dist、模型、完整知识、数据库、会话、运行状态、密钥和缓存不入库。旧通用宿主实现留在原开发设备供迁移参考，不进入公开源码清单或 wheel；旧宿主 AIAgent 的专属回归不算本项目的独立验收。

抽取 planner / executor / contracts 已迁入 `theraskill_agent.extraction`。旧脚本入口保留兼容导出，调用正式包。索引投影与 SQLite / metadata / label 构建逻辑已迁入 `theraskill_agent.indexing`，不依赖旧研究目录或外部 release QA 文件。默认模型解析、概览 API、记忆适配器和直接 provider 模板也已解除相关宿主导入。

## 验证范围

- 从显式清单导出的干净源码，在独立 Python 3.12 venv 安装开发与检索依赖后运行：**114 项通过，6 项跳过**。跳过的是依赖未随源码分发的完整模拟语言素材的集成测试。
- 四个前端构建通过。浏览器实际执行 JSONL 上传、词法构建、检索、启用、中英文切换及手机宽度检查，无页面脚本错误。
- 索引测试使用本地 HTTP 模拟 embedding 服务验证两个模型配置 / 两种维度，覆盖中断恢复、不兼容续跑拒绝、重复 ID、非法策略字段、损坏文件、分卷安装、路径越界、启用和回滚。
- 现有 Phase 6 发布文件的 200 条样本成功重建词法索引。这是兼容性检查，不是全量性能验收。
- 从 sdist 重建 wheel，在不安装旧宿主、模型框架、NumPy 或 FAISS 的环境验证抽取规划、词法构建/查询、12 个技能、6 个服务 health、模拟 HTTP 抽取到治理交接、对话管线和 UI 资源。
- 本轮本机 BGE 端点的有界测试未成功，因此不将模拟 HTTP 测试描述为真实 BGE 或远程模型质量验收。未发起全量 embedding 请求。

本地详细日志与界面截图位于 `artifacts/git-release/`，不纳入公开源码。CI 配置在 `.github/workflows/ci.yml`，将执行源码范围检查、测试、前端构建、sdist / wheel 构建和轻量安装冒烟检查。配置 CI 不等于远端 CI 已通过，需以实际运行状态为准。
