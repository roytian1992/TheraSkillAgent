## 本轮交付

| 功能 | 新行为 | 界面入口 |
| --- | --- | --- |
| 模拟患者 | 用户事实先固定；规划、档案、场景、审阅、修复、复验分阶段保存；编辑和复制后旧审阅失效 | 情景训练 → 教师/研究员 → 构建模拟患者 |
| 课程批次 | 先分配训练目标，再构建病例，最后按已保存档案检查覆盖；重试保留成功病例 | 情景训练 → 批量生成课程场景 |
| 知识抽取 | 递归 schema 校验、逐条引文定位、结论语义审阅与有限修复；全量执行记录试抽接受或显式跳过理由 | 工作区 → 知识抽取 |
| 对话评估 | 实际执行上下文/检索工具；核验轮次、原文及知识引用；综合已验证发现；后台任务与恢复 | 对话工作区 → 模型评估/打包 → 最近任务 |
| 会后复盘 | 分段覆盖完整原文，保留轮次与字符位置，成功分段可复用 | 情景训练 → 会后复盘 |
| 专家任务 | 证据、维度、建议、独立检查分开执行；教学对话支持计划、生成、检查及修复复验 | 专家工作台 |
| 回应比较 | 模型收到实际检索正文，候选知识引用必须匹配；没有知识时明确记录依据有限 | 情景训练 → 回应比较 |
| Skill 改进 | 读取失败证据、原 Skill 和参考文件，先诊断再定向改写；保留行为比较和人工审核 | 工作区 → Skill 改进 |
| 支持助手 | 增量摘要记录总结到的消息位置，补齐短消息长会话的记忆空档 | 支持助手 |

新增检查点使用现有数据目录和应用进程；没有新增业务端口或 Python 依赖。模型配置、输入或关键实现变化时，检查点失效或要求新任务，避免混用结果；凭据仅参与指纹计算。
