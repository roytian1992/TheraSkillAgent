# 课程与学习模块验收（2026-10-20）

本次范围：双语课程设计、微练习、知识辅助 LLM 评阅、教师复核、学习进展，以及生成批次转课程。完整知识和运行记录继续在源码之外管理。

## 验证方式

- 单元与 API 回归覆盖目标/量规校验、完整批次与当前审批、幂等保存、引用匹配、模型失败与重试、提交不可变、重启恢复、旧反馈失效、教师观察、评分条件与安全问题。
- 学习工作台浏览器用可控 API 数据检查交互与失败路径；课程批次浏览器用真实 FastAPI/TestClient 检查审批到保存。
- 集成测试用真实课程、作答、后台任务、证据校验和 SQLite 持久层，模型使用固定输出，验证从课程起点到教师反馈及重启恢复。
- 真实模型 smoke 使用当前配置服务与已激活知识索引，仅发送自编教学对话。它检查流程和证据接线，不是教师评分一致性研究。

## 真实模型与实际索引

- 模型：当前配置的 `deepseek-v4-pro`，没有改变持久配置。
- 输入：自编的四轮教学对话，两个课程目标；每目标分别评阅。
- 结果：36.75 秒，两个目标均返回完整、通过结构与原文引用校验的反馈。
- 检索：当前 hybrid 索引返回 6 条正文；两个目标均引用了实际知识，整体 `knowledge_grounded`。部分行为没有适用知识引用，仍明确按量规和对话判断。
- 本轮发现并修复了 managed retrieval 只返回元数据而没有正文的问题。最终候选从同一索引批量取原文，保留知识使用边界和版本信息。实际索引另外检查 6/6 条成功，正文查取约 0.007 秒。

输出保存在本地 `artifacts/learning_workflow_20261020/live_judge_smoke.json`；浏览器截图在 `artifacts/learning_ui_20261020/`，合成浏览器回归另将截图写入 pytest 临时目录。完整知识、模型配置和实际运行输出均未加入源码发布。

## 已关闭的边界问题

- 同批次并发保存最多生成一份课程；相同输入复用，不同内容返回冲突。
- 不接受缺病例、跨批次病例、旧覆盖检查或未经批准的病例回写课程。
- 教师课程目标逐字进入病例规划，无法在生成时悄悄改写；重复或无有效文字的目标在创建任务前拒绝。
- 评分仅引用实际学员原文；短练习题干作为情境证据，示范答案不进入 judge 输入。
- 旧会谈、反思、量规、模型或知识索引改变后，旧结果标记为旧版本；新评阅使用新绑定。
- 缺配置、检索故障或模型输出校验失败都有明确状态，作答与历史仍保留。
- 教师判断独立保存；不同学员、课程或练习条件不会被混成个人进步曲线，安全问题不会被另一次高分掩盖。

这些结果确认软件流程和引文接线可运行。尚未开展真实教师盲评、模型间一致性或临床量表效度研究；本轮也没有声称已在所有可配置模型上验证评分质量。
