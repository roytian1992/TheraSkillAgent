# 心理咨询课程与学习进展：设计方向与当前状态

这个模块的目标应是帮助教师组织**有目标、有依据、可反复练习的心理咨询训练**。教师先选择学员阶段和训练能力，系统组织知识、示范与案例草案，教师再调整；学员看到自己的练习证据和下一步重点，而不只是完成数量与总分。

以下是产品设计建议。参考框架提供设计方向，具体课程、评分规则和数值阈值仍需我们与教师共同验证。

## 1. 按能力组织课程，再选择来访者和场景

课程应以共同咨询能力和流派能力为基础，再加入贯穿两者的判断与反思，避免只按“焦虑、抑郁、失眠”等主诉分类。

| 能力层 | 训练内容 | 可设计的练习 |
| --- | --- | --- |
| 共同咨询能力 | 建立关系、情绪验证、共同议程、开放式评估、边界与风险沟通 | 用一轮回应准确反映情绪，再邀请来访者修正理解 |
| 流派与方法能力 | CBT 的工作假设、引导式发现、行为实验等；其他流派按各自逻辑独立组织 | 比较两个工作假设，说明为何此刻选择其中一个、如何检验 |
| 跨情境的判断与反思 | 技术选择和时机、关系破裂修复、文化与权力差异、识别自身反应 | 来访者说“你根本没听懂我”后，暂停技术推进，确认影响并修复合作 |

共同能力与特定方法组合时，要保留各方法的理论目的和适用条件。UCL 的 CBT 能力框架区分一般治疗能力、基础和具体 CBT 能力、问题特定能力及元能力，并强调理解为何及何时使用技术。[UCL CBT 能力框架](https://www.ucl.ac.uk/brain-sciences/pals/research/clinical-educational-and-health-psychology/research-groups/core/competence-frameworks/cognitive-and-behavioural-therapy)

模板先回答四件事：学员是谁、希望观察什么行为、需要哪些先备能力、什么情境能提供练习机会。案例生成随后围绕这些目标展开。**难度与风险应独立设置**：低风险案例也可以包含沉默、含糊目标、关系破裂或文化误解；提高训练难度不等于增加自伤或危机情节。

## 2. 让一次练习形成学习循环

建议把课程单元设计为：

1. **短知识卡与示范**：说明技能目的、适用时机、常见误用；比较两个回应及其后果。
2. **微练习**：只练一个行为，如反映情绪、提出一个开放问题、修复一句不当回应。可以暂停、重写和获得提示。
3. **整场练习**：在连续情境中决定是否使用技术、何时使用、何时需要改变计划。
4. **先自评再看反馈**：学员指出自己的关键选择、困惑和希望重做的一段，避免只照搬模型解释。
5. **证据反馈**：展示一项优势、一项优先改进点，以及下一次可以尝试的具体行为。
6. **变式重练与间隔回访**：保留目标，改变近期经历、表达方式或文化情境；之后再安排一次练习，观察能否保留并迁移技能。

提示可以逐步减少，但是否“独立完成”要由实际练习条件和教师标注明确记录。WHO/UNICEF EQUIP 以能力训练、角色扮演观察和督导支持技能发展；其基础助人技能材料提供模块化训练设计。这里的完整学习循环是我们据此提出的产品方案。[WHO EQUIP](https://www.who.int/teams/mental-health-and-substance-use/treatment-care/equip-ensuring-quality-in-psychological-support/) · [基础助人技能训练手册](https://www.who.int/publications/i/item/9789240105935/)

练习前后还可提供简短的学员情绪自评，例如紧张、挫败、投入程度及是否希望暂停。教师可据此调整任务节奏；这些自评不并入技能分数，也不由系统据此推断学员心理状况。

## 3. 知识应贯穿备课、练习和复盘

| 使用环节 | 检索和整理什么 | 保存什么 |
| --- | --- | --- |
| 备课 | 能力说明、先备知识、适用条件、教学示范 | 课程目标与知识卡、来源、版本、允许用途 |
| 案例设计 | 哪些行为需要观察、哪些情境能提供机会 | 目标—情境对应关系、难度与风险约束 |
| 练习支持 | 当前技能的提示和示范 | 学员看过哪些提示、何时使用 |
| 反馈 | 对应能力的观察标准和可供重练的示例 | 对话证据、标准依据、改进建议及教师修改 |

知识抽取结果可以提供教学材料候选，但**不能直接成为评分权威**。来源质量、适用人群、框架、版本和使用边界需要经过课程审核；示范性或合成材料尤其不能被包装成经验证的临床标准。

每条反馈应有两种不同的依据：

- **行为证据**：本次对话的 `turn_id`、准确引文和上下文，证明学员实际做了什么。
- **标准依据**：课程量规及引用知识，说明为什么关注这一行为。

一个知识 ID 只证明引用了材料，不能证明学员表现了某种能力。模型可提出证据和解释，教师应能修改判断并保留修改理由。

## 4. 进展页展示证据覆盖和下一步重点

把进展拆为“完成了哪些练习”“哪些行为已有观察”“在哪些条件下可以独立完成”“哪里还需督导”。建议增加：

- **未观察／不适用**：案例未提供机会时不强迫打低分。区分未出现、未能判断和确实表现不足。
- **评分条件**：记录提示程度、案例难度、量规版本、评阅者和练习时间。条件不同的分数并列展示，避免直接画成一条个人进步曲线。
- **可定位反馈**：从能力卡进入具体对话片段、自评、教师观察和下一次练习。
- **分开处理安全问题**：安全关键问题需要教师/督导处理，不能被平均分抵消；解决后保留处理记录。
- **按学员和课程分组**：群体概览展示分布与常见练习需要，个人趋势只使用该学员的记录。

原型使用的评分界限、最低练习次数和跨案例数量是**可调整的产品规则**，不是经验证量表、临床胜任力阈值或自动认证标准。APA 的督导指南采用能力框架支持受督导者发展；产品应帮助教师做出有依据的判断。[APA 临床督导指南（2025）](https://www.apa.org/about/policy/guidelines-clinical-supervision)

## 已落地的教学流程

实现包括双语课程起点、可编辑目标和行为量规、具体情境微练习、独立提交与反思、提示记录、提交后的示范讨论、按目标分步的 LLM 反馈、精确引文检查、教师独立评价、可恢复任务和生成批次回写课程。进展记录量规版本、提示条件和案例难度；不同条件不直接计算分数变化，待处理安全问题单独保留。

使用方法见[课程与学习指南](learning.zh.md)，工程验收见[验收记录](learning_validation_20261020.zh.md)。

## 后续教学研究

当前工程流程已具备让教师试用和修订的条件。之后适合与教师一起建立真实评分样本，观察模型与教师的分歧，校准不同目标的量规，并研究提示逐步减少、间隔练习与跨情境迁移的教学效果。日历提醒、正式量表或认证不属于当前实现。
