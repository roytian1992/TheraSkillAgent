# TheraSkillAgent 工作流使用说明

[English](workflows.en.md) · [部署](deployment.zh.md)

[证据检查、分阶段生成与恢复](workflow_reliability.zh.md)

启动 `theraskill-agent ui`，打开 <http://127.0.0.1:5176/>。首页增加了「技能工作流」「效果回归」「课程与学习进展」入口。已有对话文件、知识索引、支持对话、情景训练和专家治理界面继续使用同一工作台。所有业务模块均在同一进程、同一网页端口运行，无需单独启动领域服务。

## 任务与历史

从工作区开始操作，在“任务与历史”跟进执行并重新打开结果：

- **进行中与待处理**：运行、排队、等待输入或确认，以及失败、部分完成和中断的执行。
- **历史记录**：已完成或取消的执行。
- **已归档**：暂时收起的记录，可恢复。归档主任务时包含关联的抽取子任务；仍有步骤运行时不能归档。

任务类型、状态和关键词筛选共同生效，列表分页显示。试抽、全量抽取及重新规划前的抽取记录放在所属工作流下面，展开即可查看各步骤。测试记录有明确标识，默认从当前任务和历史中隐藏，在归档页可查看。归档只改变列表展示，任务原文、结果和检查点继续保留；重新运行已归档的任务后，它会回到当前列表。

这里汇总技能工作流、知识抽取、专家审核与内容生成、课程场景批次。模拟会谈、微练习、独立患者生成、对话分析和索引作业仍从各自工作区查看。某个来源暂时不可用时，页面会指出缺失的来源，其他来源仍可查看。

自动化测试使用临时目录及合成接口数据；手动验收请按[部署说明](deployment.zh.md)启动独立测试项目。测试属性来自明确的记录标识，不根据标题中的关键词猜测用户任务是否为测试。

## 技能任务与交互

在「技能工作流」选择通用技能任务，填写目标并提供文本、文件路径或上传文件。可选择已安装技能，也可让模型根据目标从技能目录选择。执行器读取完整 `SKILL.md`，由模型逐步决定调用工具、提问或完成；引用文件可通过注册工具读取。

角色不明确、schema 需确认或需要补充信息时，任务暂停在问题表单。提交答案后从同一任务继续。会写入数据的工具先显示操作和参数，确认后执行；拒绝后不会执行该调用。历史、工具结果、模型决策、问题和答案均持久保存。重新打开任务 URL 或刷新页面可恢复界面；进程异常退出后会明确标记中断，用户可从检查点恢复。失败重试保留成功结果，取消会通知正在运行的子任务。

技能中的脚本不会自动获得 shell 权限。当前可用能力包括文本整理与切分、来源检查/取样、知识检索、对话分析/评估、抽取和索引管理。依赖其他工具的技能需要实现注册适配器；Python 扩展入口为 `theraskill_agent.skill_execution.register_tool`。界面列出工具目录，不把任意 Markdown 技能都标成可直接执行。

「技能优化草稿」按优化目标调用模型生成新草稿，保存到 `data/theraskill/skill-drafts/<task-id>/`，保留原始版本和引用文件。完成草稿不代表效果提升。通过草稿中的评价链接建立对应技能的基线，再用相同案例和量规比较候选。安装新技能会扫描内容；替换已有技能（包括覆盖内置同名技能）需要已人工复核且通过的效果报告。技能及其引用文件的指纹都会参与检查。替换前保留旧版本，可在界面回滚。

命令行与界面使用同一任务存储：

```bash
theraskill-agent task create skill --goal '整理这份文本，保留原文' \
  --language zh --inputs '{"text":"示例文本","skill":"transcript-normalizer"}'
theraskill-agent task list
theraskill-agent task show TASK_ID
theraskill-agent task respond TASK_ID --values '{"answer":"补充的信息"}'
theraskill-agent task retry TASK_ID
theraskill-agent task cancel TASK_ID
```

创建/恢复命令运行到完成、失败或等待交互后返回。运行中的服务任务可从界面查看。不要并发操作同一任务；过期的界面修改会返回冲突并要求刷新。

## 从来源到知识启用

在「技能工作流」选择知识抽取。顺序为：

1. 检查来源、有限取样，模型按实际样本和目标建议抽取字段、证据字段与规则。
2. 在界面编辑 schema 和计划，明确确认后试抽。
3. 检查试抽的真实输出、来源与证据，再确认全量抽取。结果不合适可返回修改或重新规划。
4. 检查完整结果，确认交接到专家治理队列。
5. 在专家界面完成候选结构化、去重、审定、验证与预发布；评价预发布版本，通过效果对比并人工批准后才能正式发布。
6. 返回原任务，填入包含本次全部候选的正式 release ID，以及当前活动索引对应的基础知识 JSONL。系统核对基础知识指纹，合并基础语料与已发布增量，构建新索引。
7. 在效果回归页面评价候选索引，与基线比较，人工复核报告。回到原任务输入报告 ID，明确确认启用。

试抽与全量抽取具有独立且可恢复的子任务，重复派发不会新建重复任务。来源变化后不能沿用旧计划继续抽取。审核、正式发布和索引启用均有明确入口，模型不会自行完成审批。

「知识与索引」仍可独立导入、构建、验证和检索。新设备尚无活动索引时可首次初始化；更换已有活动索引时，界面、任务和 CLI 均要求通过效果报告。完整性校验与效果评价是两种独立检查。恢复上一个已启用索引无需生成新候选。

```bash
theraskill-agent knowledge activate --index CANDIDATE_DIRECTORY_ID \
  --behavior-report REVIEWED_REPORT_ID
theraskill-agent skill install /path/to/candidate --overwrite \
  --behavior-report REVIEWED_REPORT_ID
```

## 效果回归与门禁

在「效果回归」先选择案例/量规并建立基线。然后对候选知识预发布、索引或技能目录运行同一套案例，选择对应基线。每个案例实际检索证据、调用配置的 LLM 生成结果，再调用模型评价五个维度：相关性、证据依据、任务完成、语言和边界。

页面同时展示工程检查、实际输出、引用、模型评分理由、版本指纹、基线变化与人工结论。默认案例文件为 `configs/theraskill/evaluations/behavior.json`；可在界面编辑。默认12 个案例用于有界功能验证，不能代替针对目标人群、任务和边界案例建立的正式评测集。

报告只有在所有案例完整、工程检查通过、各维度达到门槛、相同量规的基线可比、没有超限回归且人工批准时才能放行。人工批准不能覆盖失败检查。知识、索引清单、技能/引用、LLM/embedding 设置或评价器变更后，旧报告不能用于批准或发布；应重新评价。报告与人工结论保留在 `data/theraskill/evaluations/behavior/`。

模型评分属于机器意见；高分和无回归不证明临床效果，也不证明优化后的技能优于旧技能。人工复核需查看实际输出和证据。

## 课程与学习进展

从课程起点开始，调整可观察行为、评分描述和练习，再分配已审核案例。学员提交短回应、保存反思，获得结合检索知识的 AI 反馈；教师独立记录观察和决定。完整案例仍按实际会话证据和配置的复盘门禁完成，进展只在条件可比较时计算分数变化。

课程生成、微练习、LLM 评分、反馈历史和进展的具体操作见[完整课程与学习指南](learning.zh.md)。

## 中英文与持久数据

各界面右上角切换中英文，偏好在本地保存。评估、支持回应、生成、任务提问与结果使用选择的输出语言。对话工作区可分别指定输入语言和界面/评估语言；原文、证据引用、既有用户内容和 JSON 字段名不会因切换界面语言被翻译。历史输出保留生成时的语言。

备份可写项目目录时，应包含 `data/theraskill/tasks/`、`data/theraskill/evaluations/`、课程数据库、业务会话、`skills/local/`、配置和知识/索引。源码升级后重启单个应用进程；不要删除数据目录。完整知识仍独立分发。

## 可视化编辑与验收

任务页支持文件上传、资源/发布/报告选择、嵌套对象和列表的可视化 schema 编辑；高级区域保留完整 JSON。长 TXT/Markdown/SRT/VTT 按配置分段并保留原文偏移，规划样本覆盖首尾。Review 默认处理全部轮次，明确报告覆盖范围和失败窗口。

行为评测的 12 个默认案例实际执行生产 TaskEngine、技能和工具链；检查任务完成、必需工具、全部必需证据家族及脚本化澄清回答是否消耗。评测不自动批准修改数据或脚本执行。报告保留执行轨迹，并绑定运行时代码指纹。

检索验收在同一页，默认 13 个中英文案例，支持 1～4 并发、1～10 次重复，显示过滤检查、通道警告和 P50/P95。相关性 0～3 分标注需填写标注人，并导出案例/标注 JSON 保存。未标注的 Recall/nDCG 不计算。小样本时延不构成服务承诺。英文 synthetic_construction 缺失作为真实数据缺口显示。

上传技能 ZIP 可先检查运行依赖；CLI 为 `theraskill-agent skill check SKILL_NAME`。缺少工具适配器或 Python 依赖时不会自动安装。`skill.run_script` 仅允许技能目录内的 Python 脚本，必须逐次批准，并保留完整输出文件；以应用用户权限本地运行，不是操作系统沙箱。上下文预算耗尽会暂停，回答预算调整问题后继续，保留原历史。
