# 部署简化与验收记录（2026-10-18）

默认部署已合并为一个应用进程、一个监听端口。情景模拟、支持助手、专家工作台、知识治理、知识抽取和文本处理保留各自的业务模块，通过进程内 ASGI 调用共享请求校验、身份检查和错误处理；无需部署六个独立 HTTP 服务。

```bash
theraskill-agent ui
# 自定义工作目录与入口端口时：
theraskill-agent --project /你的工作目录 ui --port 8080
```

默认入口为 <http://127.0.0.1:5176/>。LLM 和 embedding 继续使用各自的模型名、URL 和密钥。旧端口只用于显式的分离调试；旧版迁移步骤见[中文部署说明](deployment.zh.md)。

## 本次改动

- 工作台、agent 工具、专家工作台、贡献客户端、记忆接口和首页探测共用进程内传输。启动和退出统一管理子模块生命周期与后台任务。
- 异步接口中的同步阻塞操作改在线程中执行；后台任务仍及时返回 202，不等待模型生成结束。入口并发有上限，嵌套模块调用保留执行容量。
- 公共模型客户端对截断与空回复最多恢复两次。截断后重新生成完整结果，自动增加输出预算至最多 32768 tokens；原配置更大时保持原值。保留模型推理设置，继续检查结构化结果，不拼接残缺 JSON。
- 大语料全文查询增加执行预算。BM25 和必需知识类别通道的单次 FTS 查询预算为 2 秒；查询理解的词法通道共享 6 秒预算。SQLite 按执行回调检查超时，实际中断可能稍晚；超时和跳过的查询写入检索诊断。
- 超时回填沿用已有的必需知识类别策略，允许放宽模型建议的范围；用户明确设置的过滤条件和业务知识类别边界继续执行。这项改动优先保证任务可完成，不代表检索质量已经获得独立评测证明。
- 工作目录初始化包含本地 provider 配置示例；支持 `--project` 直接指定目录。公共示例只保留模型名、URL 和密钥等基础字段。

## 验收

- 项目回归：214 项通过，4 项已有 Pydantic 字段命名警告。
- 在测试中禁用业务 HTTP 网络连接，六个真实模块以及跨模块专家任务、贡献调用、抽取调用和文本 bundle 下载均可工作。
- 后台任务测试确认 202 返回时任务尚未完成；生命周期、启动失败清理和模型恢复上限均有覆盖。
- 真实模型故意使用 32 tokens 输出预算，收到 `length` 后自动以 8192 tokens 重新生成，获得完整 JSON；本地配置文件保持原值。
- Playwright 打开八个页面，浏览器仅访问 5176；无页面脚本错误或请求失败。390 像素页面无横向溢出。
- 浏览器提交真实专家审核，0.14 秒返回任务。最终生成成功；本次检索约 84.8 秒、回复生成约 18.6 秒。更早的首次检查发现检索约 446.5 秒；这些为少量真实任务的运行记录，不能视为严格的性能对照实验，也不构成整体任务的时延保证。模型规划和其他检索阶段仍可能较慢。
- 在不含 NumPy、FAISS、PyTorch 或旧宿主包的精简虚拟环境安装最终 wheel，并以 `python -I` 完成独立安装检查。六个模块健康检查、四个内置界面、知识示例及抽取流程通过。基础依赖未增加。
- 当前运行实例仅监听应用端口 5176；六个旧业务端口均已关闭。
