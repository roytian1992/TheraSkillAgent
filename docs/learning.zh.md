# 课程、练习与有依据的反馈

从工作台进入「课程与学习进展」，或打开 `/?workspace=learning`。这里把教师备课、短练习、模拟会谈和教学反馈连在一起。

## 教师：从课程起点备课

1. 选择「教师」和「课程设计」。可从首次会谈基础、风险与安全沟通、评估与个案概念化三个起点开始；界面语言同时决定新课程起点的语言。
2. 编辑目标、可观察行为及评分描述。起点附带知识卡和具体来访者表达，短练习的情境、任务、提示、示范回应均可修改。草稿按中英文分别自动保存在当前浏览器。
3. 查看检索到的教学材料。它们是供教师判断的候选依据，自编知识卡不会默认声称得到了全部检索结果的支持。
4. 选择已审核案例，或按当前编辑的目标生成一批新病例。难度与风险分别设置。系统先规划案例，再生成档案、检查目标覆盖；失败后重试保留已完成病例。
5. 审核生成案例。全部案例批准，且覆盖检查对应当前档案后，可「保存为课程」。修改病例会使旧覆盖结果失效，需重新检查；同一批次重复保存返回同一课程。
6. 按学员标签分配课程。沿用现有本地教学标签，无需创建新的账号体系。

## 学员：先练一个行为

选择「学员」，输入教师提供的标签并加载进展。读知识卡，选择微练习，根据具体来访者情境写出回应。查看提示会记录为使用过提示。填写反思，或明确选择暂时跳过，再提交。

提交记录保留题干、目标、评分描述、回答和提示条件，刷新后仍可查看。提交后可看示范并讨论其思路；示范不是唯一答案，也不会发送给评分器作为标准答案。再次练习会创建新记录，保留此前尝试。

点击「获取 AI 反馈」启动后台评阅，可以离开页面后再回来。模型失败时作答仍然保留，同一输入最多执行三次评阅。教师可以单独填写判断和解释，不会覆盖或冒充模型输出。切换模型、提示词版本或知识索引后，旧反馈仍保留，重新点击评阅会创建新版本；配置未变时重复点击复用已有结果。

## 把技能放入完整会谈

从任务中打开案例，练习会自动关联到任务；已有会话也可按编号关联。回到学习页，先保存该次会谈的反思，再打开反馈，也可以明确跳过反思。

AI 按课程目标逐项分析真实对话。教师记录目标评分、行为观察、带提示或独立的练习条件、迁移情境、建议和需要督导处理的问题。完整案例的完成仍要求有效会谈、配置的复盘门禁和课程要求的教师批准；短练习通过或模型给出高分都不会替代完整案例。

## LLM-as-judge 如何评分

使用平台现有的 LLM 配置和当前知识索引，不增加模型服务或部署端口。

1. 固定本次目标、量规、学员原文、情境与知识引用。
2. 根据目标和对话上下文，按 `therapy-response-reviewer` 的知识范围检索一次，保存知识 ID、索引和版本信息。
3. 每个目标分别调用模型，检查行为及使用时机；微练习只评当前要练的行为。
4. 校验目标 ID、行为覆盖、分数范围和每条引文。有分数的观察必须引用学员真实回应，知识引文必须与提供的知识原文匹配。校验失败最多请求纠正一次；仍失败则任务报错，不展示不完整分数。
5. 展示优势、下一次可练的行为、对话依据与知识依据，保留模型、提示词、输入指纹和检索来源。教师意见独立记录。

「未观察」表示本次机会或证据不足，「不适用」表示本次练习不需要该行为，两者都不计为零分。已经观察到的不合适回应可以低分，但需引用学员实际说的话，说明为何不合适。不会因为患者顺从、开心或披露更多而直接加分，也不会根据高分推断学员独立完成。

知识用于辅助解释，课程量规仍由教师决定。没有适用知识时标明「按课程标准反馈」。精确引文校验解决出处可核对的问题，模型解释仍需要教师判断；目前的评分用于教学反馈，不是经验证的临床胜任力量表。

## 如何看进展

进展分开显示案例完成情况、教师观察和重复练习记录。趋势按学员、课程分组，只有量规、难度与提示条件可比较时才计算分数变化。修改会谈或量规会使旧批准失效。待处理的安全问题保留到教师重新复核，另一次高分不会将其隐藏。

下一步建议指向继续练习、教师复核、督导或之后换情境重练。当前不包含日历提醒和临床认证。

## 部署与数据

继续在现有模型配置页管理 LLM 与 embedding。无索引时可按课程标准评阅，安装知识资源后增加检索依据。旧课程仍可读取；旧批准如果没有量规指纹，需要重新复核才能计入当前量规的通过记录。

备份模拟会谈 SQLite 数据库、学习反馈任务目录、生成病例和课程批次任务。默认反馈目录位于病例批次目录旁，名为 `<数据库文件名主体>_learning_judge_jobs`。启动时自动创建新增数据表，不需要重置数据库。

部署见[部署文档](deployment.zh.md)，测试范围见[验收记录](learning_validation_20261020.zh.md)。

设计参考：[WHO/UNICEF EQUIP](https://www.who.int/teams/mental-health-and-substance-use/treatment-care/equip-ensuring-quality-in-psychological-support/)支持按可观察助人技能训练与督导的方向；[LLM-as-judge 研究](https://arxiv.org/abs/2306.05685)提示需要明确标准并关注评分偏差，其通用基准结果不等于心理咨询教学评分已有效度验证。
