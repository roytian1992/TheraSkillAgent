# 构建与复用模拟患者

在情景训练页切换到“研究员”或“教师”，使用“构建模拟患者”。可以只填写
训练主题，让当前配置的 LLM 生成草稿，也可以展开档案直接填写并保存。
手动构建不调用模型；不需要预先安装完整场景资源，也不增加服务端口或依赖。

患者档案包含公开身份与当前困扰、生活背景、近期经历、情绪、患者目标、
训练目标、隐藏顾虑、表达习惯与披露偏好。每条经历分别记录发生时间、内容、
影响及稳定事件 ID。它们是会谈开始之前的合成病例事实，与会话中产生的记忆分开。

背景和经历分别选择“开始即可透露”“建立信任后透露”或“深入探索后透露”。
时间、事件与影响作为同一事实进入披露图。编译器依据对话状态和治疗师动作
选择本轮允许进入模型上下文的事实，避免把整份隐藏档案直接交给患者表达模型。
这是上下文控制，不保证模型绝不编造或转述，仍需检查实际对话。

## 保存、修改与复用

生成/手动保存后，场景持久保存在项目的 `data/theraskill/`：

- `simulation/generated_scenarios.jsonl`：场景注册信息、版本、审核状态和病例引用。
- `simulation/generated_cases/`：不可覆盖的病例版本文件，内含完整档案及 Persona v2。
- `simulation/sessions.sqlite`：练习轨迹、会话状态与记忆。

“查看和编辑患者档案”可以补充经历、调整披露层级并保存新版本。保存后
审核状态恢复为草稿；批准后进入学员可复用场景。编辑器携带读取时的版本号，
若别人已修改则返回冲突，避免静默覆盖。正在进行的会话和从它创建的复盘
使用创建时的病例版本，新会话使用新版本。

“复制为新场景”保留当前档案、创建独立场景，可为同一患者设计不同近期事件。
资源包中的既有病例也可以先复制，再编辑。单纯复用同一病例可以直接再次开始
训练；如果需要承接上次对话的状态，使用已有的后续会话功能，后续会话也保留
原会话的病例版本，防止旧记忆与新设定混杂。

## Skill 与知识支撑

Skill 工作流选择 `simulated-patient-builder`，例如输入：

> 构建一个工作反馈后自责的模拟来访者，补充上周的两件经历，用于练习共情
> 与开放式提问。家庭顾虑暂不公开，保存供以后继续编辑。

Skill 的 `theraskill_patient` 工具支持 generate、build、inspect、update、fork，
与网页使用同一业务接口和存储，通过进程内调用工作，不需要额外 API 服务器。
字段示例见 [patient-schema.md](../plugins/theraskill/skills/simulated-patient-builder/references/patient-schema.md)。

在线生成默认从活动知识索引检索构建知识，并保存实际返回的来源 ID、索引 ID
及检索状态。索引不存在、检索失败或没有匹配时明确记录，仍可生成未获检索支撑
的合成草稿。知识用于设计训练目标与披露，不会被当作该患者真实发生的经历。
生成表单可以关闭检索。

## 在线生成的分阶段流程

在线生成依次执行规划、档案、场景包、独立审阅；存在问题时定向修复，再次审阅。用户填写的事实在构建场景和审阅前固定，审阅对象与最终保存的患者及角色卡一致。空审阅、无效修复或审阅不可用都不会成为“通过”。

界面立即创建后台任务，展示当前步骤；刷新后可找回进度，失败可从未完成步骤继续。已完成步骤及场景 ID 保持不变。同一次 Agent 工具调用重试也会复用检查点。输入、模型配置或实现改变时需要新建任务。

编辑和复制使旧的模型审阅失效。治理区展示未解决的问题，可点击“重新检查当前版本”；教师明确人工覆盖时必须填写理由，结构阻断项仍需先修正。

课程批次先规划各病例的训练目标和近期经历，再逐个构建。最后读取实际保存的患者档案，检查目标覆盖和重复；修改不足病例后可重新检查课程。生成保持请求中的风险、难度和场景类型。

其他任务的证据核验和恢复方式见[工作流可靠性说明](workflow_reliability.zh.md)。

## 运行方式与检查边界

快速患者模式对 Persona v2 病例先分析当前治疗师动作，再生成患者回应，并在
后台更新状态与记忆（通常两次前台模型调用、两次后台调用；修复或重试可能增加）。
它省去独立的模型披露决策调用，由编译器控制可用事实。界面等待后台同步完成后
开放下一轮，失败时可以重试。双模型研究模式也会完成双方状态/记忆更新。

结构检查检查档案、人设、近期经历、训练目标与重复描述；它不等同于行为验收
或临床质量评价。生成草稿需要教师复核，模型复盘需要结合完整对话阅读。
当前时间线采用人工/模型填写的时间描述，尚不提供通用日历推演或自动跨会话
生成新生活事件。修改下一次会谈经历时，编辑或复制场景后再创建新会话。
